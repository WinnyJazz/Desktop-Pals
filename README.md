# Desktop Pals

Desktop Pals is a desktop companion application built with Electron. It is designed to provide a small companion on your desktop while you work, study, or relax.
⚠️currently underconstruction tehee
## Features

* Interactive desktop pet
* Lofi music player
* Pomodoro timer

## Tech Stack

* Electron
* HTML
* CSS
* JavaScript
* Bootstrap
* YouTube

## Getting Started

### Install Dependencies

```bash
npm install
```

### Run the Application

```bash
npm start
```

## Status

This project is currently a work in progress. Features and functionality are still under development.
